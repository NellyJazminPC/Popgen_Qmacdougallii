# Assembly, variant calling, and SNP filtering with ipyrad and TASSEL

This directory contains the VCF files generated from alternative ipyrad
assemblies and the corresponding post-assembly filtered datasets evaluated
during selection of the final SNP panel for downstream analyses.

![Overview of the ipyrad assembly and TASSEL filtering workflow](Diagrama_flujo_ensambles_ipyRAD.png)

## Assembly strategies

Three trimmed-read datasets were evaluated:

- `trim01`
- `trim02`
- `trim03`

Each dataset was assembled using the following strategies:

- *de novo* assembly;
- reference-based assembly using the *Quercus lobata* genome;
- reference-based assembly using the *Quercus robur* genome.

Two alternative ipyrad parameter sets were evaluated for each combination
of trimming dataset and assembly strategy.

### Parameter set 1

```python
("clust_threshold", "0.70")
("pop_assign_file", "popmap_9sites_2zones_trim01.txt")
```

### Parameter set 2

```python
("min_samples_locus", 79)
("clust_threshold", "0.90")
```

The `clust_threshold` parameter defines the minimum sequence-similarity
threshold used to identify homologous reads and cluster them into loci.
A value of `0.90`, for example, requires at least 90% sequence similarity.

Very high clustering thresholds may prevent homologous reads from being
grouped because of sequencing errors, polymorphisms, ambiguous bases, or
insertions and deletions.

The `min_samples_locus` parameter specifies the minimum number of samples
that must contain data at a locus for that locus to be retained in the
final dataset. In the first parameter set, sample-retention criteria were
instead supplied through the population-assignment file.

## Post-assembly VCF filtering

VCF files generated by ipyrad were subsequently filtered using
TASSEL v5.2.95 through:

> Filter > Filter Genotype Table Sites

The following settings were applied:

- Site Minimum Count: 79
- Site Minimum Allele Frequency: 0.00
- Site Maximum Allele Frequency: 1.00
- Remove Minor SNP States
- Remove Sites With Indels

## Final SNP dataset

The `trim01` datasets produced the largest numbers of retained SNPs under
all three assembly strategies. The reference-based assembly using the
*Quercus robur* genome produced the largest final dataset and was selected
for downstream analyses.

The final VCF used in the genetic diversity, population structure,
demographic history, and outlier analyses was:

`ref_gen_qrob_trim01_1_sorted.vcf`

This dataset contained:

- 7,611 SNPs in the original ipyrad VCF;
- 5,501 SNPs after the first TASSEL filtering step;
- 5,426 SNPs after the final filtering step.

The `_sorted.vcf` suffix identifies the post-filtered and sorted VCF used
as the common input for downstream analyses.
