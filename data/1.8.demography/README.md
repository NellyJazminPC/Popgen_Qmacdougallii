# Demographic-history data

This directory contains selected inputs and retained outputs from the
demographic-history analyses of *Quercus macdougallii*.

## `easy_sfs_one_pop/`

Contains selected easySFS output generated by treating all 79
individuals as a single population.

A folded one-dimensional site-frequency spectrum was prepared using a
projection of 156 chromosomes.

## `stairway/`

Contains the six final Stairway Plot summary files used to generate the
combined demographic-history figure.

The scenarios combine three mutation rates:

- 1.01 × 10^-8 substitutions per site per generation;
- 4.2 × 10^-8 substitutions per site per generation;
- 5.2 × 10^-8 substitutions per site per generation;

with generation times of:

- 50 years;
- 100 years.

The retained summaries were generated with `ninput = 200`.

The corresponding Stairway Plot blueprint files are stored under:

`bin/2.3.demographic_history/blueprints/`

The files are:

- `pop1_1.01e8_50y_demography_analysis.final.summary`
- `pop1_1.01e8_100y_demography_analysis.final.summary`
- `pop1_4.2e8_50y_demography_analysis.final.summary`
- `pop1_4.2e8_100y_demography_analysis.final.summary`
- `pop1_5.2e8_50y_demography_analysis.final.summary`
- `pop1_5.2e8_100y_demography_analysis.final.summary`

These files provide the time-scaled median effective population-size
estimates and confidence intervals used by the plotting script:

`bin/2.3.demographic_history/2.3.1_plot_stairway_plot.py`

Complete Stairway Plot working directories are retained locally and
are not distributed through GitHub.
