# Demographic-history data

This directory contains the site-frequency-spectrum files used for the
demographic-history analyses of *Quercus macdougallii*.

## `easy_sfs_one_pop/`

Contains easySFS output generated by treating all 79 individuals as a
single population.

A folded one-dimensional site-frequency spectrum was prepared using a
projection of 156 chromosomes. The retained files include output in
dadi and fastsimcoal2 formats and the associated easySFS data
dictionary.

The population map used for this analysis is:

`data/structure_formats/popmap_one_pop.txt`

The filtered VCF used to generate the SFS is available from Zenodo:

`https://doi.org/10.5281/zenodo.20548053`

## Local Stairway Plot outputs

Stairway Plot working directories and final summary files are generated
locally under:

`data/1.5.demography/stairway/`

These generated outputs are not distributed through GitHub.

The plotting script expects the following six final summary files in
that local directory:

- `pop1_1.01e8_50y_demography_analysis.final.summary`
- `pop1_1.01e8_100y_demography_analysis.final.summary`
- `pop1_4.2e8_50y_demography_analysis.final.summary`
- `pop1_4.2e8_100y_demography_analysis.final.summary`
- `pop1_5.2e8_50y_demography_analysis.final.summary`
- `pop1_5.2e8_100y_demography_analysis.final.summary`

The corresponding Stairway Plot blueprint files are distributed under:

`bin/2.3.demographic_history/blueprints/`

The combined visualization is generated with:

`bin/2.3.demographic_history/2.3.1_plot_stairway_plot.py`
