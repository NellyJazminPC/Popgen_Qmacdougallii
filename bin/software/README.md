# Bioinformatics software

This directory was used locally to store bioinformatics software required by
the preprocessing, assembly, and SNP-filtering workflow.

The software installations and executable files are not distributed through
this repository. The corresponding scripts retain the commands used during
the analyses.

## Software versions

### FastQC v0.11.9

Used to assess the quality of the raw and trimmed sequencing reads.

- Software: [FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/)
- Citation: Andrews S (2010). FastQC: A Quality Control Tool for High
  Throughput Sequence Data.

### Trimmomatic v0.39

Used to generate the three alternative trimmed-read datasets.

- Software: [Trimmomatic](http://www.usadellab.org/cms/?page=trimmomatic)
- Citation: Bolger AM, Lohse M, Usadel B (2014). Trimmomatic: a flexible
  trimmer for Illumina sequence data. *Bioinformatics* 30:2114–2120.

### ipyrad v0.9.85

Used for de novo and reference-based assembly and variant calling.

- Software: [ipyrad](https://ipyrad.readthedocs.io/)
- Citation: Eaton DAR, Overcast I (2020). ipyrad: Interactive assembly and
  analysis of RADseq datasets. *Bioinformatics* 36:2592–2594.

### TASSEL v5.2.95

Used to filter the SNP datasets generated by ipyrad.

- Software: [TASSEL](https://www.maizegenetics.net/tassel)
- Citation: Glaubitz JC, Casstevens TM, Lu F, et al. (2014). TASSEL-GBS:
  a high capacity genotyping by sequencing analysis pipeline.
  *PLoS ONE* 9:e90346.
