# Sample metadata

This directory contains public metadata for the 79 *Quercus
macdougallii* individuals included in the population genomic analyses.

## File

`Qmacdougalli_79ind_.csv`

The file contains one row per individual and 11 columns:

- `SITE_NAME`: ordered sampling-site code.
- `ID`: individual identifier.
- `MUN`: municipality.
- `NUM_IND`: original numeric identifier.
- `SITE_NUM`: sampling-site label.
- `POP`: population grouping.
- `NOM_IND`: sample identifier.
- `specie`: species name.
- `POP_ASIG`: assigned population.
- `ZONE`: geographic zone (`NORTH` or `SOUTH`).
- `NUM_SAMPLE`: combined site and individual identifier.

The dataset includes nine sampling sites from three municipalities.
