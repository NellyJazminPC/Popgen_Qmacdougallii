# Results

This directory is used for tables, figures, logs, and intermediate
outputs generated by the analysis scripts.

The main result categories include:

- genetic diversity and differentiation;
- population structure;
- SNP outlier detection;
- sequence annotation and BLAST results;
- candidate SNP allele plots.

Specific output files are described in the README for each analysis
module under `bin/`.

Generated results are retained locally and are not distributed through
GitHub. Only this README is version-controlled.
